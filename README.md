**CivicShield** is a civic empowerment platform for Indian citizens — a Flutter application
that puts the power of law knowledge, enforcement accountability, and community action in
every citizen's pocket.

Built for the **Hackathon MVP** and aligned with **UN SDG 9** and **SDG 16**.
